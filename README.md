# Intervue Login Automation

This repository contains a Selenium-based automation script to test the login functionality of [Intervue.io](https://www.intervue.io).

## Features
- Automates login using provided credentials.
- Captures a screenshot (`login_failure.png`) if login fails.

## Prerequisites
- Python 3.7+
- Google Chrome browser (latest version)
- Required Python libraries:
